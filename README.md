# 🎓 Student Placement Prediction System

## Overview

A Machine Learning web application that predicts whether a student is likely to be placed based on academic performance and profile.

---

## Features

- Predict Placement Status
- Logistic Regression Model
- 88.37% Accuracy
- Flask Web Application
- Beautiful Responsive UI
- Confidence Score
- Data Visualization
- Complete Machine Learning Pipeline
